# Generated typed DAG accuracy gate (v1)

This harness measures endpoint candidate precision and recall on bounded, deterministic FastAPI source trees generated by `benchmarks/real_world/typed_dag_accuracy.py`. Its endpoint oracle is derived from the fixture generator's declared call-edge table, independently of analyzer output. It covers cross-file calls, alias imports, a reconvergent helper graph shared by two routes, live lambdas and awaited coroutines, and dead/unrelated negative controls. The analyzer is invoked through the installed CLI in `--secure-ast --no-cache` mode; fixtures are synthetic and are never imported or executed.

Run it from the repository root:

```sh
uv run python benchmarks/real_world/typed_dag_accuracy.py \
  --output benchmarks/results/typed-dag-accuracy-v1/current-main.json
```

The command exits nonzero unless every supported case has 100% precision and recall and every dead/unrelated control has zero HIGH/MEDIUM candidates. LOW candidates are recorded separately as report-only. Each case stores its baseline and target source material, diff, config, SHA-256 hashes, expected endpoints, actual endpoint/confidence rows, and TP/FP/FN metrics. The document records the source revision, harness hash, tool/dependency versions and hashes, full declared case coverage, limitations, and unresolved status. The validator recomputes metrics and gate status, checks finite values and candidate/case uniqueness, verifies input hashes, and rejects missing cases.

Addition, deletion, and rename fixtures include explicit paired source snapshots and diffs, but are currently marked `unsupported`: the shipped mypy `ChangeMapper` does not map these changes against paired baseline/target symbol graphs. They do not count toward a pass. Re-run this gate after dependency integration; an unsupported or failed case never becomes a guessed pass.

This generated subset is one GH283 milestone only. It does not close or satisfy GH283's normalized corpus milestones, the blind release corpus gate, bootstrap guard, or incremental performance gate. It changes no canonical truth, publication, or ledger data.
